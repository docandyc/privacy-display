# Balance Readability-Priority OCR Tables to N=324

## Goal

Make the OCR tables use a balanced estimand across profiles by collapsing the
disclosed second capture round for five readability-priority content items
within each content--geometry--repeat unit.

## Requirements

- Preserve all raw capture records and disclose that 459 short-exposure images
  and 153 videos were collected for readability-priority.
- Average duplicate readability-priority captures within their matched unit.
- Report 324 short-exposure units and 108 video units for
  readability-priority, matching the other profiles.
- Recompute every affected mean, interval, exact-match rate, leak rate, and
  per-engine value; do not relabel the existing raw-capture statistics.
- Update the English manuscript and the canonical analysis artifact/script
  needed to reproduce the balanced numbers.
- Preserve unrelated user edits already present in `paper/main.tex`.

## Acceptance Criteria

- [ ] Table `tab:real_ocr_full_pool` contains no 459/153 analysis rows and
  clearly defines N as duplicate-averaged units.
- [ ] Table `tab:real_ocr_engine` reports N=324 for every profile/engine row.
- [ ] All affected prose and figure captions use the balanced estimand.
- [ ] Generated analysis results reproduce the manuscript values.
- [ ] Relevant tests pass and `paper/main.tex` compiles without new errors.

## Definition of Done

- Statistical source, manuscript values, and methodological wording agree.
- Raw collection counts remain transparently disclosed.
- Regression tests cover duplicate averaging for per-engine summaries.

## Technical Approach

Use the existing capture-unit parser and duplicate-cell rule:
`mean within profile + attack + content_item + position + repeat_index`.
Compute summaries and bootstrap intervals over those collapsed units. This
retains both capture rounds without giving the five repeated items extra
weight.

## Decision (ADR-lite)

**Context:** Readability-priority has 459 raw short-exposure captures because
five of twelve content items were captured twice, while other profiles have
324. Reporting raw-capture means creates an unbalanced weighting.

**Decision:** Collapse duplicate captures within the pre-existing matched unit
and report balanced unit counts.

**Consequences:** The readability-priority point estimates and uncertainty
summaries must be recalculated. Raw archive counts remain part of the data
provenance but are not used as table N.

## Out of Scope

- Deleting raw captures.
- Re-running OCR engines.
- Changing the capture design or attack definitions.
- Rewriting unrelated Chinese manuscript copies unless they are generated by
  the project’s established synchronization workflow.
