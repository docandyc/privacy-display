# 精修翻译执行约束

将 `paper/main.tex` 的最新内容同步到 `paper-Chinese/main.tex`。

1. 以 `research/01-analysis.md` 的术语和证据边界为准。
2. 译文应像中文研究者直接撰写的论文，句法自然，但不得调整原文论证、数据或主张强度。
3. 保持所有 LaTeX 命令、数学公式、标签、引用键、图路径和表格结构正确。
4. 复用现有中文稿中已经稳定的译法；只改动英文源自 `e8916ef` 后变化的内容及结构核对发现的遗漏。
5. 完成后逐项核对章节、图表、标签、引用、数字与英文残留，再执行 XeLaTeX + BibTeX 编译验证。
